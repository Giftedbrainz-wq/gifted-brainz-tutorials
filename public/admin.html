Create CBT

Fixed by subject: Mathematics = 50 minutes; all other subjects = 40 minutes.
UTME CBT rule: every CBT must contain exactly 40 questions. The platform provides five CBTs per subject. Physics, Chemistry and Biology must contain 8 Roman-numeral questions (20%) using statements I–IV. English and Mathematics do not use this Roman-numeral requirement.

Question Bank

Build the reusable subject question bank manually, or extract numbered A–D questions from a PDF, Word or text document. After every import the console tells you plainly whether the questions were extracted properly, and flags any question whose correct answer could not be read from the document.

Manually add a question

English passage-setting guide: first create one clear Passage Group ID (for example ENG-P03), paste the complete passage once in Shared passage, then add each question that belongs to that passage. Use the same Passage Group ID for every related question. Do not paste a different passage into each question unless it is intentionally a new passage.

App Update

Publishing an update makes the new version live immediately. The server validates the package, extracts the required web files securely, and publishes them to the update channel. Students receive only the web assets needed to run the new version — the original ZIP is never sent to a student's device.
